# Changelog

## 0.1.0 — 2026-11-14

Initial public beta.

- Native Ubuntu tray menu for Codex usage.
- Remembers multiple accounts and workspaces with last-checked timestamps.
- Five-hour and weekly readings when returned by Codex; reset countdowns.
- Current-account refresh every minute and on demand.
- Fictional demo mode isolated from live account data.
- User-local installer, optional login startup, and uninstaller.

Tested on Ubuntu 24.04 / GNOME with Codex 0.169.0. Signed-out accounts retain saved readings; they do not refresh automatically.
